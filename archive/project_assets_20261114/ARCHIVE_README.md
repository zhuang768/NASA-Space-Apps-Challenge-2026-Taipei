# Historical project companion assets

Private team handoff, 2026-11-14. These are historical research, QA, computed Earth data, workbook support and UI snapshots, not the authoritative current MS-01/MS-02/MS-03 release. Do not overwrite current main with this tree. Original relative layout is retained beneath this directory.

185 of the 186 manifested assets included. The full EH1 published article is omitted because redistribution rights were not verified; its provenance file links the original source. Four QA/inventory files have personal absolute paths replaced with PROJECT_ROOT. No scientific values were modified.

University Valley source data: Marinova, Data from NASA project to study ice-cemented ground in and around University Valley Antarctica, Zenodo v1, https://doi.org/10.5281/zenodo.10553882 ; CC0 per publisher API. Other scientific observations and derived results retain source attributions in their provenance/QA; no blanket relicensing is asserted.

No credentials, environment files, dependency caches, raw 12 GB Earth download batch, or the two already published workbook/screening files were added. ARCHIVE_MANIFEST.json lists exact paths, hashes, modifications and omissions. Historical status text is preserved as history, not a current completion claim.
