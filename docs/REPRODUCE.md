# Reproduce the three Mars targets

Use a fresh clone or working copy: rebuilding replaces local generated outputs. The published PDF and its original manifests are frozen, as-produced `MARS-RESELECT-20261114-v1` records. The cleaned runtime generates `MARS-RESELECT-20261114-v1-clean` artifacts with their own provenance.

## Environment and original inputs

The numerical workflow was tested with Python 3.12.15 on an Apple Silicon Mac, using CPU only. Install the pinned Mars-only dependencies from the repository root:

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

[The input manifest](../config/raw_inputs_manifest.json) lists 11 public PDS, SWIM, Montabone and Zenodo files, their URLs, byte counts and SHA-256 checksums. Downloaded originals and the derived stack are excluded from Git. Download missing originals explicitly:

```sh
.venv/bin/python -m scripts.download_mars --download
```

Existing files are checked rather than silently replaced; a size or checksum mismatch stops the workflow. To check local originals without network access, use `--verify-only`. No private account or archived project checkout is required. MEDA remains inherited rover-local quality context in `config/source_context.json`; its raw files are not needed for these new targets.

## Numerical rebuild

After obtaining the originals, run these commands in order:

```sh
.venv/bin/python -m scripts.build_mars_stack
.venv/bin/python -m scripts.research.mars_reselection_20261114
.venv/bin/python -m scripts.research.mars_reselection_20261114 --finalize-targets outputs/research/mars_reselection_20261114/fixed_targets.json
.venv/bin/python -m scripts.research.mars_reselection_20261114 --validate
```

The first command builds the 0.5-degree stack. The next runs the full exploratory screen; fixed-target extraction then reproduces the A/D/C evidence underlying MS-01/MS-02/MS-03. Validation checks the produced files, source support, time-bin pairing and Pareto set.

The complete `screened_pool.csv.gz` is generated by screening and need not be stored on GitHub. Run screening and extraction before validation; downloading source files alone does not create the comparison pool.

The equivalent numerical-only entry point is:

```sh
.venv/bin/python -m scripts.rebuild --download --skip-report
```

Omit `--download` when all checksum-verified originals are already present.

## Rebuild the report

Install a font containing Traditional Chinese glyphs, such as Noto Sans CJK, and supply its real path:

```sh
.venv/bin/python -m scripts.reporting.build_mars_reselection_report --font /path/to/NotoSansCJK-Regular.ttc
```

`MARS_REPORT_FONT` provides the same override; installed Mac or Noto CJK fonts can also be discovered automatically. The all-in-one `scripts.rebuild` entry point accepts `--font` as well. Rebuilt PDFs require a new visual review; numerical validation does not certify page layout.

## What reproduction establishes

Packaging, code provenance, timestamps, fonts and NetCDF serialization can change artifact hashes. The clean stack also has measured global-array differences, recorded in [the cleanup rebuild check](../outputs/research/mars_reselection_20261114/cleanup_rebuild_validation.json); it is not claimed to be byte-identical to the original stack. In the tested rebuild, comparison-pool and Pareto memberships, the 22 review coordinates/order and all 88 native numerical columns were unchanged; dust and MCS sequence files reproduced exactly. Original lineage is retained in `config/source_context.json`.

No GPU, model training or generated observations are required. Rebuilding does not repeat the bounded literature search, establish global novelty, confirm ice resources or validate landing, extraction or equipment performance.
