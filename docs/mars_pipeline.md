# 火星端管線與隊友交接

本輪負責火星端。地球原始資料、QA、特徵處理及地球候選配對交由隊友；現有地球程式留存，本輪沒有修改地球端模組。

## 已實際接入

已同步主分支 `9f62d89` 上傳的 7 個火星資料產品及 3 個 PDS 標籤。逐一比對本次分析來源的 SHA-256 與 GitHub 對應 Git blob，10 個檔案均一致。沒有把文件清單當成原始檔。

| 資料 | 本輪用途 | 重要尺度與限制 |
|---|---|---|
| MOLA MEGDR | 地形、坡度、起伏 | 16 px/degree；areoid 高程；分析用 3396 km 球半徑；來源含插值與軌跡空隙 |
| TES 夜間熱慣量＋插值遮罩 | 原生格點區域摘要及 0.5°堆疊 | 20 px/degree；單位 J m^-2 K^-1 s^-0.5；遮罩 0 是插值填補，正式摘要排除它；不是溫度或地面硬度 |

## 執行

Mars 原始檔已在 Git；clone／pull 後通常不用重下載。若缺檔可執行既有下載入口。

```bash
.venv/bin/python scripts/download_mars.py
.venv/bin/python scripts/build_mars_stack.py
.venv/bin/python scripts/score_mars_selftest.py
.venv/bin/python scripts/profile_mars.py --strict
.venv/bin/python -m pytest -q
.venv/bin/ruff check .
```

`profile_mars.py --targets targets.json` 可指定目標。JSON 以目標 ID 為鍵，各項需提供火星 `lat`、東經 `lon`；建議一併填 `label` 和 `coordinate_source`，設計假設也要寫明。明確標為其他天體的目標會拒絕。

缺檔時摘要保留 unknown；`--strict` 會因缺檔或讀取失敗回傳非零，不把尚未完成的來源當成可用資料。沙塵來源實際為 classic NetCDF，使用 SciPy reader；不需要為這兩個檔案改動地球端 HDF4 環境。

## 兩種輸出尺度

### 100 km 目標描述

`outputs/mars_profiles/` 包含 Jezero、Gale、專案設計 Arcadia 中心的描述值與六份沙塵 CSV。

- 地形使用 100×100 km 視窗、4 km 點距與 8 km 內部差分跨度。
- TES／SWIM 在相同實體視窗內選取原生格點中心；均值按 cos(latitude) 近似面積加權，並列原生格數、有效格數及比例。缺測不外推。這是格心納入法，不是精確裁切格子面積。
- TES 同時列出排除插值、包含插值兩種摘要，方便看出依賴程度。
- 沙塵選最近的原生 3°格點，保留格點座標，**不宣稱它是 100 km 視窗內的獨立觀測**。提供均值、95 百分位、最大值、峰值 sol／Ls 及四段 Ls 摘要；95 百分位不是 95% confidence。
- `cdodtot` 為當地總柱吸收光學厚度，`cdod610` 為 610 Pa 正規化值，`cdodrel` 是供應者可靠度欄位，不是氣壓正規化或校準後的機率。

### 0.5°火星 stack 與內部檢查

保留並修正隊友的 `analog/stack.py`、`sites.py`、`score.py`。0.5°是火星內部的共同顯示／描述網格，不能直接套用相同度數與地球比較。

已修正：

- SWIM 聚合倍率改由緯度座標間距決定。2400 列涵蓋約 120°，不是 180°；目前倍率為 10，不是舊算法的 7。
- 對 SWIM 所有經度正規化，包含略小於 -180°的來源格點；不只檢查東界是否超過 180°。不支援的旋轉或投影參數會報錯。
- TES stack 排除插值遮罩為 0 的值。
- 沙塵映射到 0.5°時採最近原生格，保留 3°來源尺度標記；沒有增加真實細節。
- 經度重採樣處理週期邊界；缺乏緯度涵蓋仍保留 NaN。
- 相似度預設要求全部正權重圖層有資料。若明確允許部分資料，逐格按可用權重正規化並輸出 `evidence_fraction`。這是「所要求圖層可用比例」，不是信賴度。
- 零變異且完全相同的圖層可正確得到零差距；負權重會拒絕；角度去重處理日期變更線。`separation_deg` 仍是角度排除框，不能宣稱固定公里間隔。

IQR 尺度、0.1 倍全域 IQR 下限及預設等權均是未校準設計。Arcadia 內部檢查的參考框為 38–48°N、180–160°W，與上述 100 km Arcadia 中心視窗不同，不應混用兩種特徵。

本次重跑，內部檢查第一名在 44.25°N、170.25°W，位於參考框內，分數約 0.940。這是用同一火星資料建立並檢查描述值的行為檢查，不能證明科學選址有效，更不是地球候選驗證。

## 還缺什麼

| 項目 | 現況與需要補的內容 |
|---|---|
| 可比較的火星地表溫度 | 尚缺可與地球 LST 對齊的日夜表面溫度、季節與當地時刻；不能用 TES 熱慣量充當 K 或 °C |
| 任務與門檻 | 尚未定義具體任務、材料／環境條件、權重及通過門檻；目前只有描述值與實驗性內部相似度 |
| 地質、礦物與資源 | 尚缺目標區礦物／地質證據與資源可用性；SWIM／PFR 不能直接證明可採水冰 |
| 細尺度地形與現場驗證 | 公里級資料不能判定石塊、輪胎落點、細部通行或基地安全 |
| 跨行星沙塵比較 | Earth 550 nm extinction AOT 與 Mars 9.3 μm absorption CDOD 的轉換及環境假設尚待驗證；本輪不自動乘係數後宣稱等價 |
