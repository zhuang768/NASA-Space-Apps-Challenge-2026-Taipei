# 選點方向：使用者確認的第一項構想

2026-11-14（Asia/Taipei）。供 GPT 與 Cursor 共同閱讀；後續工作仍由使用者分配。

## 核心目標

找出被忽略、研究較少，且對某個特定任務有價值的候選點。地點不必各方面都完美，也不必取得最高綜合分數；重點是找出它的特色、適合完成的事情，以及可支持這個用途的證據。

## 已確認的選點原則

1. **優先新穎或研究較少的點。**尋找既有候選名單未收錄，或尚未被充分研究的地點，發掘其被忽略的價值。
2. **以特定用途說明價值。**每個候選點都要回答「它特別適合做什麼？為什麼？」；用途尚未由使用者指定，不能直接當成已定案的任務需求。
3. **允許局部優勢與明確缺點並存。**其他條件普通，也可能因某項特色而值得研究；需要一併交代不適合的條件與類比限制。
4. **避免重複發現。**已被提出或推薦為相同用途的已知場址，不得重新包裝成我們的新發現。有一般研究、但特殊用途尚未被提出的地點，仍可查證其新價值。
5. **保留可驗證的資料依據。**「既有候選名單沒有」不等於「沒有任何量測資料」。缺值不能當作新穎性或適用性的證據。
6. **新穎性需要查證。**對照既有場址名單與文獻，再說明已知研究及我們補充的價值；未查到紀錄時，只能如實標示查核範圍與待確認事項，不能直接宣稱從未有人研究。

## 後續候選說明應包含

- 地點、座標與研究範圍。
- 已有研究／候選收錄情況，以及尚未充分探索之處。
- 特別適合的用途及其資料證據。
- 已知缺點、資料缺口與尚待驗證的主張。

這份紀錄只保存使用者已確認的方向；尚未執行新的搜尋、排除名單、排名或文獻查證。
