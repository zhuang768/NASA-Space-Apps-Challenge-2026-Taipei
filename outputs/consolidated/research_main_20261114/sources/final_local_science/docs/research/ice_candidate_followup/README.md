## 給 Reporting 的結論

**兩點都暫時保留為「淺層冰資源探查的研究候選區」，新穎性仍未通過。** 原始資料可重現目前數值，沒有發現必須因資料缺失而換點的理由；這並不等於確認有冰、適合採冰，或適合載人基地。

## 還不能說的話

- 「35% 是冰」「94% 的信心／適合度」：這些數值沒有這種意義。
- 「一公尺內一定有冰」「已找到可開採的水源」：尚無本單元的獨立深度、純度、連續性與開採驗證。
- 「較高深度圖數值＝冰更多」：不同深度合成指標不能當成含量比較；兩圖也共用輸入 [S1]。
- 「這裡沒人研究過／第一次被提出／已證明少研究」：新穎性尚未通過。
- 「坡度低所以能安全降落／鑽探」：公里尺度平均坡度看不到小石塊、坑壁、土壤強度等現地風險。
- 「熱慣量就是地表溫度」：本 JSON 沒有地區性的日夜／季節地表溫度。

熱訊號對埋藏冰的判讀也有物理限制。2026 年研究摘要指出，熱探測對超過約 30 cm 深的冰之敏感度會快速下降 [S6]。這不能反過來否定本點有冰，但足以說明單靠熱性質不能確認一公尺內的可挖冰層。
