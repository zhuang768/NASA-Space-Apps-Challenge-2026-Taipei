# ZASA｜問題分派與驗收

每個問題獨立驗收。有來源、可重現及有明確缺件的項目，與「科學問題已解」必須分開。正式報告由隊伍自行撰寫。

| 問題 | 負責方向 | 驗收標準 |
|---|---|---|
| 火星冰真值 | 原位／獨立測量查核 | 三個固定框內、實際共址、量測敏感度足以辨識冰；沒有資料就留未知 |
| 冰深及含冰量 | 雷達／熱模型可辨識性 | 深度、精度及體積／質量基準分開；不把見不到反射當作無冰 |
| MS-01 物性／控制 | 地球材料與物理限制 | 同位置／同材質的 k、ρCp 與已知冰／無冰；模型不能替代現地控制 |
| MS-01 站位 | 原始 GPS／部署資料 | 綁 logger serial 的位置與時期；調查表只支持不定案 |
| MS-01 / 03 時鐘 | 時序科學驗證 | 同 logger 對照與跨 logger 分開；不擅自平移時標 |
| MS-02 候選 E02 | 原始地球測量／關聯 | 單點已知與場址結論分開，核對用途、可比較的時空尺度 |
| MS-02 候選 E04／地質定位 | GIS 座標及單元查核 | 官方座標基準、獨立 CRS 回轉、原單元證據與可用空間 |
| MS-02 雷達同址、高程／覆土 | 共址感測與替代解釋 | 區分觀測、數值雜波與厚度模型；配不到就不晉升 |
| MS-03 三份原表 | 期刊／官方檔案查核 | 取得真正原表內容及校驗；錯誤 HTML 和 DOI metadata 不等於原表 |
| MS-03 多邊形 | 影像幾何與可量測性 | 檢視範圍、有效覆蓋、地標精度不同；維持可量測性限制 |
| MS-03 光譜／T1811 | 產品處理與科學 QA | 原始程式版本、係數、mask、中間資料；未看到不能斷定生產根因 |
| MS-03 AD1 交叉定位 | 原始 GIS／感測幾何 | 標明端點、坐標基準與圖幅；未共址不作點位真值 |
| 地球類比新穎性 | 異地／同地同用途先例審查 | 搜尋規則可追溯，但不宣稱全球無先例 |
| GitHub 主線整合 | 凍結版本、驗收與保護使用者報告 | 核對每個 PR／blob、保留現有正文、驗證合併實際狀態 |
| 公開站部署 | 應用介面、建置、預覽、正式驗收 | 檔案校驗、桌面／手機互動、signed-out 版號、可回滾 |
| 最終展示／投稿核對 | 獨立展示驗收 | 公開 Demo 與 Final Project 分開；團隊自己核對正式提交與回執 |
