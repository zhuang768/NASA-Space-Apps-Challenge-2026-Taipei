## 新診斷定義與界線

- 參照 [Smerdon 等 2003 §3.1 ¶10](https://doi.org/10.1029/2002JB002351) 的均質、半無限、一維、穩態週期熱傳形式，若上／下層的半振幅比為 R，則最簡模型的相位落後應為 `q = −ln(R)` rad。令 `ω = 2π/24 h`，預測相位落後（以小時表示）是 `q/ω`。這是用已知解析式建立的檢核，不是新方法。
- 本輪新值 `Δ = wrap24(觀察相位落後 − q/ω)`，輸出到 [−12,+12) 小時。`Δ` 是兩個相位的**圓周差**，不是實際熱傳行程時間，也不是時鐘錯誤大小。
- D36 36 cm 的觀察相位原值 −10.833h，僅表示模 24h 相位；加一圈可寫 13.167h，但不能據此宣稱「實際落後 13.167h」。表保留原值及圓周計算，不藉挑圈數修時鐘。
- 四個冰界面通道的 Δ：S8 `−0.822h`、M22 `−1.201h`、D36 `−1.656h`、W42 Campbell `−1.824h`。各完整結果、同站其他深度與 12h 干擾諧波敏感度在 `amplitude_phase_consistency.csv`。這些只是與最簡假設的描述性不一致，不是統計拒絕、冰診斷、材料反演或時鐘校正。
- 逐一刪除 11 個印刷日，各冰界面 Δ 範圍分別為 `−0.851 至 −0.786h`、`−1.700 至 −0.893h`、`−2.451 至 −1.262h`、`−2.721 至 −1.350h`。它們不是信賴區間、不是獨立重複試驗、也不包括感測器系統誤差；逐次值另存 `leave_one_day_diagnostics.csv`。
- 同站較深通道的日諧波半振幅可小於殘差 RMSE（CSV 同列保留兩者）。因此不能把穩定的刪日結果當成準確相位或模型成立的證明。短視窗、非週期擾動、分層／邊界／探針耦合皆可能影響結果；本輪不判定其中哪一個是真因。

## 時鐘問題可以與不可以結案的部分

- **可結案：共同常數時標原點不是本站內比值／相位差的必要前提。** 對保留的同一批列，將所有通道時標一同平移 −13、−5、−1、+0.371、+1、+5、+13h，再做相同擬合；11 組 R／Δ 的最大數值差小於 `4.3e-14`。sin/cos 係數共同旋轉，振幅和相對相位不變；中心化線性趨勢也不變。結果見 `clock_origin_invariance.csv`。
- 這只是對**共同常數偏移**的代數性質與數值單元測試，既不測出真實偏移，也不獨立證實每個探針的物理同步。測試沒有移動取樣窗或重選列。若用 UTC／太陽時挑選新視窗，沒有核實絕對時鐘仍會選錯資料。
- **不能結案：** 不同 logger 間的偏移、時計漂移、reset、通道延遲、真實 UTC／地方太陽時、2012 Campbell 邊界問題。本輪不使用 2012 資料，也不嘗試移位對齊 W42 的分開 U23 logger。
- 必要原件仍是相關 logger serial 的啟動／卸載／校時、reset 或輸出程式紀錄，以及時間標準與頻率。若只想使用本輪站內描述性圖，不必等這些紀錄；若要跨 logger 相位、日照因果或絕對相位，沒有它們就停止該主張。
