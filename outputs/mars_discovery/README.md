# Mars site discovery (Matching role)

Generated by `scripts/discover_mars_sites.py` on the 0.5° Mars stack.

## What this is

Purpose-driven **within-Mars** shortlists for three task screens:

1. `isru_shallow_ice` — higher SWIM shallow-ice consistency + low slope
2. `dusty_flat_ops` — higher dust optical depth + flat plains
3. `firm_rocky_surface` — higher TES thermal inertia + moderate relief

Famous boxes are **excluded** from the shortlists: Jezero, Gale, Arcadia, Utopia (cyan on the maps).

## Outputs

- `mars_site_discovery.json` — signatures, weights, top picks, layer values
- `figures/*_map.png` — score maps with excluded boxes and top picks marked

## What this is not

- Not proof a site is “never studied” (literature checks still required)
- Not Earth–Mars ranking (Earth handoff remains separate)
- Not landing approval, ice quantity, or confidence
